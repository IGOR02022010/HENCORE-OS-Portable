## 🚀 Запуск ОС

Для запуска HENCORE OS Portable откройте файл **`index.html`**, расположенный в корне архива.

> 💡 **Подсказка:** просто дважды щёлкните по файлу — система откроется в браузере, установленном по умолчанию.

---

## 🖥️ Запуск через локальный сервер

Если нужно запустить систему как локальный HTTPS-сервер, откройте файл **`RUN_SERVER.py`** — он тоже находится в корне архива.

> ⚠️ **Требование:** для работы сервера необходим установленный [Python](https://www.python.org/downloads/).

---

## ⚠️ Важные предостережения

> **НЕ удаляйте системные файлы!**
> Удаление или изменение системных файлов может привести к поломке ОС и потере её работоспособности.
